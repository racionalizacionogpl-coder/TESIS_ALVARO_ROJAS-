# ProjectCard

Tarjeta de proyecto con código, estado, avance real contra planificado y SPI.

Datos: `code`, `name`, `tone` y `status` (semáforo), `real` y `plan` en %, `spi` y `onOpen`. `featured` pinta la tarjeta en `teal-600`: úsalo para un solo proyecto por grilla, el que más atención exige. La marca vertical de la barra es el avance planificado a la fecha de corte.
