# StatusPill

Píldora de estado con punto y palabra; el color nunca va solo.

`tone`: `ok` (En control), `warn` (En observación), `crit` (Crítico), `idle` (Sin línea base) o `info` (En curso, en turquesa). Sin `children` muestra la palabra predeterminada del tono; con `children`, la palabra que pases («Vencida · 4 d»). No la uses para categorías ni como decoración.
