# Countdown

Panel marino con cuenta regresiva en vivo (días, horas, minutos y segundos) hasta el próximo hito.

Pásale `target` (fecha ISO o milisegundos), `title` (nombre del hito) y opcionalmente `label` (por defecto «Próximo hito»). Se actualiza cada segundo y se detiene en cero. Usa uno por vista, en la franja principal del proyecto.
