# Icons

Set propio de líneas: 24 × 24 px, trazo 1.75 px, extremos y uniones redondeados, sin relleno. Los archivos vienen en una sola tinta `ink` (#0F2240) para usarse como `<img>`; en la interfaz se insertan en línea con `currentColor` (componente `Icon`) para que tomen blanco sobre `teal-600` y `navy-900`.

- `portafolio`: cartera de proyectos.
- `alerta`: alertas críticas.
- `cronograma`: actividades y Gantt.
- `riesgo`: riesgos abiertos.
- `acuerdo`: acuerdos y compromisos.
- `equipo`: personas, equipo e interesados.
- `hito`: hitos.
- `curva`: avance y curva S.
- `cambio`: control de cambios.
- `asesor`: informe con IA.
